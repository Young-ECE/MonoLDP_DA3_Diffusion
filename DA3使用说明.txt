Depth Anything V3 (DA3) 集成使用说明
=====================================

## 安装 DA3

```bash
# 方式 1: 从 GitHub 安装（推荐）
pip install git+https://github.com/ByteDance-Seed/Depth-Anything-3.git

# 方式 2: 如果已发布到 PyPI
pip install depth-anything-3
```

## 使用方法

### 基本训练命令

```bash
cd DepthEstimation
python train.py \
    --use_diffusion \
    --use_depth_anything_v3 \
    --depth_anything_v3_model DA3Mono-Large \
    --data_path /path/to/your/data \
    --batch_size 6 \
    --num_epochs 15
```

### 使用本地模型

如果模型已下载到本地：

```bash
python train.py \
    --use_diffusion \
    --use_depth_anything_v3 \
    --depth_anything_v3_model DA3Mono-Large \
    --depth_anything_v3_weights /path/to/DA3Mono-Large \
    --data_path /path/to/your/data
```

### 下载模型

从 HuggingFace 下载模型：

```bash
# 使用 git clone
git clone https://huggingface.co/depth-anything/DA3Mono-Large

# 或使用 huggingface-cli
huggingface-cli download depth-anything/DA3Mono-Large
```

## 参数说明

- `--use_depth_anything_v3`: 启用 DA3 作为教师模型
- `--depth_anything_v3_model`: 模型名称（目前支持 DA3Mono-Large）
- `--depth_anything_v3_weights`: 本地模型路径（可选）

## 注意事项

1. DA3 需要额外的依赖包，请先安装
2. 首次使用会自动从 HuggingFace 下载模型（需要网络）
3. 如果网络不通，请手动下载模型并使用 --depth_anything_v3_weights 指定路径
4. DA3 模型较大，需要足够的显存（建议 12GB+）

## 模型对比

- DA3Mono-Large: 高质量相对单目深度估计，几何精度更高
- 相比 DA2: 性能显著提升
- 相比传统教师: 无需预训练，开箱即用
