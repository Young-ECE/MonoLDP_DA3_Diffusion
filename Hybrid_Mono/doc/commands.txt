# MonoLDP 常用命令

## 环境配置

### 创建conda环境
```bash
conda create -n monoldp_depth python=3.8
conda activate monoldp_depth
pip install -r requirements.txt
```

### 安装Depth Anything V3
```bash
# 设置HuggingFace镜像（可选，加速下载）
export HF_ENDPOINT=https://hf-mirror.com

# 安装DA3
pip install git+https://github.com/ByteDance-Seed/Depth-Anything-3.git
```

## 训练命令

### 基础训练
```bash
cd DepthEstimation
python train.py \
  --model_name monoldp_diffusion_model \
  --data_path /oldisk/home/jingyang/monoldp/datasets/nyu_data \
  --batch_size 2 \
  --num_epochs 15 \
  --learning_rate 5e-5 \
  --scales 0
```

### 指定GPU训练
```bash
# 使用GPU 0（默认）
python train.py --gpu_id 0 ...

# 使用GPU 1
python train.py --gpu_id 1 ...

# 使用GPU 2
python train.py --gpu_id 2 ...

# 或者使用cuda_device参数
python train.py --cuda_device cuda:1 ...

# 使用CPU（禁用CUDA）
python train.py --no_cuda ...
```

### 完整训练命令（带所有参数）
```bash
cd DepthEstimation
export HF_ENDPOINT=https://hf-mirror.com
python train.py \
  --model_name monoldp_diffusion_model \
  --data_path /oldisk/home/jingyang/monoldp/datasets/nyu_data \
  --batch_size 2 \
  --num_epochs 15 \
  --learning_rate 5e-5 \
  --scales 0 \
  --diffusion_l1_weight 1.0 \
  --diffusion_ddim_weight 1.0 \
  --log_dir /oldisk/home/jingyang/monoldp/temp
```

### 使用训练脚本
```bash
bash train_with_da3.sh
```

## 模型评估

```bash
cd DepthEstimation
python evaluate_nyu_depth.py \
  --data_path /oldisk/home/jingyang/monoldp/datasets/nyu_data \
  --load_weights_folder <模型权重路径> \
  --batch_size 6 \
  --num_workers 8 \
  --scales 0
```

## 单张图像推理

```bash
cd DepthEstimation
python inference_single_image.py \
  --image_path <图像路径> \
  --load_weights_folder <模型权重路径>
```

## TensorBoard查看训练日志

```bash
# 查看最新训练日志
tensorboard --logdir /oldisk/home/jingyang/monoldp/temp

# 查看指定实验
tensorboard --logdir /oldisk/home/jingyang/monoldp/temp/monoldp_diffusion_model_YYYYMMDD_HHMMSS

# 指定端口
tensorboard --logdir <日志路径> --port 6007
```

## 远程服务器使用

### SSH端口转发（查看TensorBoard）
```bash
# 在本地终端执行
ssh -L 6006:localhost:6006 username@remote_server

# 然后在远程服务器启动tensorboard
tensorboard --logdir <日志路径>
# 在本地浏览器打开 http://localhost:6006
```

### Screen会话管理
```bash
# 创建训练会话
screen -S train

# 执行训练命令
# ... 训练命令 ...

# 分离会话: Ctrl+A, 然后按 D

# 查看所有会话
screen -ls

# 恢复会话
screen -r train

# 退出会话
exit

# 进入回滚模式: Ctrl+A, 然后按 ESC
```
